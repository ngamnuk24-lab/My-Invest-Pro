# My Invest v1.1 — US Stocks / USD-first

## ขอบเขต
- ใช้กับหุ้นและ ETF ในตลาดสหรัฐฯ เท่านั้น (NASDAQ / NYSE) ใช้ Ticker เช่น AAPL, MSFT, NVDA, AMZN
- ยึดโครงสร้างและฐานข้อมูล My Invest v1.1 (IndexedDB `my-invest-db`, DB version 2) เพื่อคงข้อมูลเดิม
- ใช้งานออฟไลน์ได้: บันทึกซื้อขาย/ทรัพย์สินตั้งต้น/รายการติดตาม/ราคาที่เคยบันทึกไว้ได้ในเครื่อง
- เมื่อออนไลน์ ดึงราคาอ้างอิงหุ้นผ่าน Yahoo Finance Chart endpoint โดยใช้ CORS proxy สาธารณะ ไม่ต้องสมัคร ไม่ต้องใช้ API Key และไม่มีค่าบริการในตัวแอป
- FX USD/THB ใช้ Frankfurter API v2 ซึ่งไม่ต้องใช้ API Key และเป็นอัตราอ้างอิงรายวัน

## จุดที่ปรับปรุง
1. เพิ่มแท็บ “ราคา” เป็นฐานราคากลาง (ราคา USD, มูลค่าเทียบ THB, เวลาอัปเดต, แหล่งข้อมูล) ทุกแท็บอ้างอิงราคาจากฐานเดียวกัน
2. Dashboard แสดง Donut แยกตามหุ้นที่ถือจริง พร้อมเปอร์เซ็นต์การจัดสรรรายตัว
3. เพิ่มกำไร/ขาดทุนรายหุ้น แสดงทั้ง THB และ USD
4. ทุกหน้าหลักแสดงมูลค่า THB เป็นหลักและ USD ควบคู่กัน
5. ราคาหุ้นบันทึกเป็น USD; FX ของรายการซื้อ/ขายและทรัพย์สินตั้งต้นถูกเก็บ ณ เวลาบันทึกเพื่อคงต้นทุนเงินบาทในอดีต
6. FX ปัจจุบันใช้แปลงมูลค่าตลาดล่าสุดเป็น THB โดยไม่เขียนทับ FX ของธุรกรรมเดิม
7. Watchlist ตัวอย่างเป็นหุ้นสหรัฐฯ เท่านั้น
8. อัปเดตราคาอัตโนมัติเมื่อกลับมาออนไลน์ และทุก 5 นาทีขณะเปิดแอป/ออนไลน์ พร้อมปุ่มอัปเดตเอง
9. ยังคงสำรอง/กู้คืน JSON และใช้ข้อมูล local IndexedDB

## สำคัญเรื่องราคา
- ไม่มี API หุ้นฟรีที่รับประกัน real-time/uptime/สิทธิ์การแสดงผลเชิงพาณิชย์ได้ทุกกรณี
- Yahoo Finance Chart เป็น endpoint ไม่เป็นทางการ อาจมีความหน่วง เปลี่ยนแปลง จำกัดการเรียก หรือหยุดให้บริการได้ จึงเรียกว่า “ราคาล่าสุดที่ผู้ให้บริการส่งกลับ” ไม่รับประกัน Real-time
- CORS proxy เป็นบริการภายนอกฟรีและอาจมีข้อจำกัด/หยุดให้บริการได้
- Frankfurter ให้ FX อ้างอิง ไม่ใช่ราคา FX แบบ tick-by-tick; อัปเดตตามผู้ให้บริการต้นทาง
- หาก API ดึงไม่ได้ แอปจะคงใช้ราคาล่าสุดที่เก็บในเครื่อง และสามารถแก้ไขราคาด้วยตนเองได้
- ตรวจสอบราคากับโบรกเกอร์ก่อนส่งคำสั่งซื้อขายเสมอ

## วิธีติดตั้งบน iPhone
1. แตก ZIP แล้วนำไฟล์ในโฟลเดอร์ `my_invest_pwa` ไปโฮสต์บน HTTPS
2. เปิด URL ด้วย Safari ขณะออนไลน์ครั้งแรกเพื่อให้ Service Worker cache ไฟล์
3. กด Share → Add to Home Screen (เพิ่มไปยังหน้าจอโฮม)
4. เปิดแอปและกด “อัปเดตราคาและ FX” เพื่อดึงข้อมูลล่าสุด
5. ใช้เมนูสำรองข้อมูลเพื่อส่งออก JSON เป็นระยะ

## การคงข้อมูลจาก v1.1
- ใช้ DB name และ DB version เดิม จึงเปิด IndexedDB เดิมต่อได้ ไม่เปลี่ยนโครงสร้าง stores
- ก่อนใช้งานเวอร์ชันนี้ ให้ส่งออก JSON จากแอปเดิมไว้ก่อน
- รายการเดิมที่ระบุตลาดเป็น SET/HKEX/TSE/OTHER หรือรหัสต่างประเทศที่มี suffix ตลาดจะไม่ถูกรวมในพอร์ต US; ข้อมูลเดิมยังคงอยู่ใน IndexedDB แต่ไม่แสดงในยอดคำนวณของรุ่นนี้

## สูตร
- ต้นทุนเงินบาทของ BUY = (จำนวน × ราคาซื้อ USD + ค่าธรรมเนียม USD) × FX ณ วันที่บันทึก
- มูลค่าตลาดปัจจุบัน THB = จำนวนคงเหลือ × ราคาหุ้น USD ล่าสุด × FX USD/THB ปัจจุบัน
- Unrealized P/L THB = มูลค่าตลาด THB − ต้นทุนเงินบาทคงเหลือ
- USD equivalent เป็นค่าประมาณโดยแปลงยอดเงินบาทด้วย FX ปัจจุบัน
- ใช้ Average Cost สำหรับคำนวณต้นทุนและกำไร/ขาดทุน ไม่ใช่ระบบภาษีที่สมบูรณ์
